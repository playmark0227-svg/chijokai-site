管理画面にログイン

「法人の方へ」ページの案件一覧を、ここから追加・編集・並べ替えできます。
「公開する」を押すと、1〜2分でサイトに反映されます。

制作担当からお渡しした github_pat_ で始まる文字列です。ブラウザに「パスワードを保存しますか」と聞かれたら保存しておくと、次回から自動で入ります。

合言葉はパスワードと同じです。人に送ったり、メールやメモに貼ったりしないでください。このページは合言葉を GitHub 以外には送らず、ページの中にも残しません（閉じると消えます）。有効期限が切れたら「ログインできません」と出るので、制作担当に新しいものをご依頼ください。

制作担当向け：合言葉（トークン）の発行手順
  1. リポジトリ chijokai-site を持つ GitHub アカウントで新しい fine-grained トークンの作成画面を開く。
  2. Token name に 知上会 管理画面（堀之内さん） など、誰に渡したか分かる名前を入れる。Expiration は 90日 程度にする（無期限にしない）。
  3. Repository access は Only select repositories で chijokai-site だけを選ぶ。
  4. Permissions → Repository permissions の Contents を Read and write にする（ほかは付けない）。
  5. Generate token で表示された文字列を、安全な方法で先方に渡す。渡した相手と期限を控えておき、期限前に作り直す。

この管理画面は、ほかの案件サイトと同じアドレス（playmark0227-svg.github.io）の下にあります。そのため、ページがトークンをブラウザに保存することはしていません。知上会の独自ドメインに移ったら、この制限は緩められます。
